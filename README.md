# 城端小学校 当日レジアプリ

## GitHub Pagesへのアップロード

1. GitHubで新しいリポジトリを作成します。
2. このフォルダ内の `index.html` をリポジトリ直下へアップロードします。
3. リポジトリの `Settings` → `Pages` を開きます。
4. `Deploy from a branch` を選択し、`main` / `(root)` を指定して保存します。
5. 表示された公開URLをスマートフォンで開きます。

## 会計記録について

- 会計記録は使用した端末・ブラウザ内に保存されます。
- 複数端末の記録は自動統合されません。
- 各端末でレジ名を設定し、終了後にCSVを出力してExcelでまとめてください。
- ブラウザの履歴やサイトデータを消す前に、必ずCSVを出力してください。

## ファイル構成

- `index.html`：レジアプリ本体。画像や外部ファイルは不要です。
